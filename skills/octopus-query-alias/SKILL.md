# 章鱼：中文话题研究入口

读取本入口相邻的 `../octopus/SKILL.md` 并遵循其引用的研究规则。

- “章鱼，帮我研究下这个话题”调用主技能；“这个话题”优先从上下文确定，缺少主题时才询问。普通聊天讨论章鱼这种动物本身不触发研究。
- 提取用户的主题、目的、时间与地区范围；以指定主题为准，不局限于 AI、科技和商业。只有未指定主题的综合信息发现才默认关注这些领域。
- 每日/今天请求采用每日增量流程，具体主题近况默认 30 天；专题知识归纳按问题补充背景和历史资料，不受 30 天硬性限制。
- 用户调用技能或明确要求信息搜集、近期查询、研究、比较时应用；普通闲聊提及话题、单纯改写或归纳已提供材料，不自动联网采集。
- 只问技能规则、状态或审计时，只检查文件，不启动研究。
- setup 仅在用户明确要求时运行。没有明确同意，不提取或索要浏览器 Cookie；普通调用显式使用 `FROM_BROWSER=off`。
- 新鲜事实、证据、输出和历史记录规则统一维护在主技能中，不另设冲突模板。
